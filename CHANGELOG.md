# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-06-30

### Added

- Real-time multiplayer chess puzzle logic (2-4 players)
- PWA Support (Manifest, Service Worker, Splash Screen)
- Advanced AudioManager with normalized sound effects and volume control
- Beautiful Glassmorphism UI with Tailwind CSS v4
- Admin/Teacher panel for custom puzzle uploading via JSON
- Dynamic Victory and Podium screens with Confetti animations
- WebP optimized assets for instant loading

### Optimized

- Fully optimized image resources (PNGs converted to WebP)
- Removed unused dependencies (lottie-web, etc.)
- Setup caching for production via vite-plugin-pwa
