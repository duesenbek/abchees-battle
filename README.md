## 📖 О проекте

**ABCHESS BATTLE** — это пет-проект интерактивного образовательного веб-приложения, созданный для превращения решения шахматных тактических задач в динамичную очную дуэль.

### Проблематика

Обычные шахматные тренажеры рассчитаны на индивидуальное тихое решение задач перед персональным монитором. При проведении групповых занятий, мастер-классов или школьных турниров ученикам часто не хватает соревновательного азарта и мгновенного визуального результата на общем экране.

### Решение

Приложение позволяет запустить соревнование на одном экране (мониторе, интерактивной доске в классе или проекторе) в режиме **Split-Screen**. 2 или 4 участника одновременно решают одну и ту же цепочку шахматных задач, видя прогресс соперников, серии побед (комбо) и таймер в реальном времени.

## ✨ Ключевые возможности

- 🎮 **Split-Screen Мультиплеер:** Поддержка 2 или 4 независимых интерактивных шахматных досок на едином мониторе/доске.
- ⚙️ **Встроенный шахматный движок:** Валидация ходов по официальным шахматным правилам с помощью `chess.js`, проверка легальности и учет очередности ходов.
- ⏱️ **Real-time динамика:** Живой таймер, подсчет очков, комбо-множители за безошибочные серии и индикаторы оставшихся попыток.
- 🏆 **Экран победителя (Podium):** Автоматический подсчет результатов раунда с праздничным пьедесталом и подробной статистикой (затраченное время, процент правильных ходов, допущенные ошибки).
- 🛠️ **Панель учителя / Администратора (Admin Studio):**
  - **Библиотека наборов:** Предустановленные тактические паки (Мат в 1 ход, Мат в 2 хода, Связки, Вилки, Двойной шах, Пешечные окончания).
  - **Импорт задач:** Загрузка собственных задач через JSON-файл или копирование текста с поддержкой AI-генератора промптов для ChatGPT/Claude.
  - **Интерактивный предпросмотр:** Визуальный просмотр начальных позиций на доске, FEN-нотации и алгоритмов победных решений до старта игры.
  - **Кастомизация раунда:** Настройка времени, допустимых попыток, лимитов подсказок, имен игроков и 45 разнообразных 3D-аватаров.
- 📱 **PWA & Offline:** Установка приложения на десктоп или планшет, кэширование статических ассетов и работа без доступа к интернету.
- 🔊 **Web Audio синтезатор:** Звуковое сопровождение ходов, правильных ответов, предупреждений таймера и победных фанфар без задержек сети.

## 🚀 Быстрый старт

### Требования

- [Node.js](https://nodejs.org/) версии 18 или выше
- Менеджер пакетов `npm`, `pnpm` или `yarn`

### Установка и запуск

1. **Клонируйте репозиторий:**

   ```bash
   git clone https://github.com/duesenbek/abchees-battle.git
   cd abchees-battle
   ```

2. **Установите зависимости:**

   ```bash
   npm install
   ```

3. **Запустите сервер для разработки:**

   ```bash
   npm run dev
   ```

   Приложение откроется по адресу `http://localhost:5173`.

4. **Сборка для продакшена:**

   ```bash
   npm run build
   ```

5. **Предпросмотр продакшен-сборки:**
   ```bash
   npm run preview
   ```

## 🧩 Формат пользовательских задач (JSON)

Вы можете загрузить собственный набор шахматных задач через вкладку «Импорт задач» в Панели администратора. Пример поддерживаемой структуры:

```json
{
  "title": "Мат в 1 ход: Базовые комбинации",
  "difficulty": "Легкая",
  "description": "Подборка задач на обнаружение мата ладьей и ферзем.",
  "puzzles": [
    {
      "id": "custom-1",
      "fen": "r1bqkb1r/pppp1ppp/2n5/4p3/2B1n3/5Q2/PPPP1PPP/RNB1K1NR w KQkq - 0 4",
      "solution": ["f3f7"],
      "description": "Поставьте детский мат белым ферзем."
    }
  ]
}
```
