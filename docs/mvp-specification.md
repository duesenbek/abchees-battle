# Спецификация проекта «Шахматная дуэль» (Chess Battle)

Интерактивная многопользовательская платформа для решения шахматных задач в соревновательном формате.

- **Репозиторий:** [duesenbek/abchees-battle](https://github.com/duesenbek/abchees-battle)
- **Демо (Production):** [abchees-battle.vercel.app](https://abchees-battle.vercel.app/)
- **Автор / Разработчик:** [duesenbek](https://github.com/duesenbek)
- **Стек технологий:** React 19, TypeScript, Vite, Zustand, chess.js, react-chessboard, Tailwind CSS v4, PWA.

---

## 1. Проблема

Во время групповых и индивидуальных занятий часто не хватает соревновательной динамики и моментальной визуализации прогресса. Стандартные шахматные платформы ориентированы на последовательное индивидуальное решение задач и не приспособлены для организации очных мини-турниров между несколькими участниками на одном экране.

В результате снижается вовлечённость, особенно среди детей и начинающих шахматистов, которым критически важен интерактивный игровой формат.

## 2. Цель проекта

Создать высокопроизводительный, отзывчивый веб-модуль для проведения шахматных соревнований на одном устройстве (Split-screen 1v1 или 2v2) или интерактивной доске. Проект превращает рутинное решение тактических упражнений в захватывающую дуэль с мгновенной валидацией ходов, анимациями и звуковым сопровождением.

## 3. Ключевые возможности

### 3.1. Игровой режим (Split-screen Duel)
- Запуск состязания на одном экране (монитор, интерактивная доска, планшет);
- Поддержка конфигурации на 2 или 4 независимые игровые зоны;
- Отображение интерактивных шахматных досок с поддержкой drag-and-drop и кликов;
- Автоматическая валидация ходов по правилам шахмат на базе движка `chess.js`;
- Отображение очков, серий правильных ответов (комбо), шкалы прогресса и оставшегося времени в реальном времени;
- Экран завершения раунда (Подиум) с объявлением победителя и детальной аналитикой ошибок/времени.

### 3.2. Панель управления и библиотека задач (Admin Studio)
- Предустановленная библиотека тактических наборов (Мат в 1 ход, Мат в 2 хода, Связки, Вилки, Двойной шах, Эндшпиль);
- Инструмент импорта пользовательских задач через JSON-файл или текстовое поле;
- Встроенный генератор промптов для создания задач с помощью нейросетей (ChatGPT, Claude);
- Интерактивный режим предпросмотра задач с отображением начальной позиции, FEN и цепочки правильных ходов;
- Гибкая настройка параметров раунда: таймер, лимит попыток на задачу, лимит подсказок, темы доски.

### 3.3. PWA и автономность
- Полная поддержка PWA (Progressive Web App) с манифестом и сервис-воркером;
- Возможность установки на рабочий стол и планшеты;
- Кэширование ресурсов и поддержка офлайн-режима;
- Синтез звуков через Web Audio API без зависимости от сетевых аудиофайлов.

## 4. Архитектура и качество кода

- **Архитектурный подход:** Модульная Feature-based структура (`core`, `features`, `shared`).
- **Изоляция состояния:** Управление состоянием турнира через `Zustand` без лишних ререндеров.
- **Масштабируемость:** Подготовлены сервисные контракты для будущего добавления сетевого мультиплеера (WebSockets).
- **Типобезопасность:** 100% строгий TypeScript с валидацией пользовательских входных данных (JSON-схемы).
