# Дорожная карта проекта «Шахматная дуэль» (Roadmap)

Проект разбит на логические этапы (спринты) для обеспечения высокого качества (Premium Quality) и планомерного достижения целей MVP 1.1.

## ✅ Этап 1: Базовая архитектура и состояние (Завершено)
- [x] Инициализация проекта (Vite, React, TypeScript, Tailwind CSS v4).
- [x] Проектирование типов данных (`Puzzle`, `PlayerProgress`, `GameSession`).
- [x] Создание глобального хранилища состояния (Zustand: `useGameStore.ts`).
- [x] Разработка базовых компонентов UI (`GameZone.tsx`, `Leaderboard.tsx`).
- [x] Динамическая поддержка 2 или 4 игровых зон.

## 🚀 Этап 2: Сборка главного экрана и логика раундов (Текущий фокус)
**Цель:** Связать компоненты воедино и запустить полноценный игровой цикл.
- [ ] **Главный Layout (`App.tsx`)**: Размещение `Leaderboard` по центру и `GameZone` по краям (режим 1v1 или 2v2).
- [ ] **Состояния экранов**:
  - *Экран подготовки (Setup/Lobby)*: Выбор количества игроков, ввод имён.
  - *Экран игры (Active)*: Активные доски, работающий таймер.
  - *Экран результатов (Completed)*: Показ победителя, статистика, кнопка рестарта.
- [ ] **Интеграция таймера**: Запуск `tick` каждую секунду при старте игры.

## ⚙️ Этап 3: Панель администратора (Преподавателя)
**Цель:** Дать возможность учителю гибко управлять контентом урока.
- [ ] **Компонент `AdminPanel.tsx`**: Панель настроек перед стартом.
- [ ] Возможность загрузки кастомных задач в формате JSON (FEN + Решения).
- [ ] Настройка лимита времени на раунд.
- [ ] Принудительный старт/сброс раунда.

## 🎨 Этап 4: Полировка, UX и Геймификация (WOW-эффект)
**Цель:** Сделать интерфейс сочным, интерактивным и привлекательным для детей.
- [ ] **Аудио-сопровождение**: Интеграция звуковых эффектов на перемещение фигуры, правильное/ошибочное решение, победные фанфары.
- [ ] **Микроинтеракции**: Доработка анимаций (тряска при ошибке, пульсация при правильном ходе), добавление эффектов конфетти при победе.
- [ ] **Адаптивность (Responsive Design)**: Гарантия идеального отображения на планшетах, ТВ и проекторах, которые часто используются в школах.

## 🧪 Этап 5: Тестирование и подготовка к релизу
**Цель:** Обеспечить безотказную работу на живых занятиях.
- [ ] Ручное тестирование крайних случаев (например, превращение пешки, одновременные ходы разных учеников).
- [ ] Оптимизация производительности рендеринга досок.
- [ ] Финальная сборка и инструкция по запуску (`build`).
